# Wordle

A small offline Android Wordle game built with Kotlin and Jetpack Compose.

## Play modes

- **Daily** uses the same answer for everyone on a given calendar day.
- **Unlimited** picks a new random answer whenever you start a new game.

## Build

Open the project in Android Studio or run:

```sh
./gradlew test assembleDebug
```

The project requires JDK 17 and Android SDK platform 35.
